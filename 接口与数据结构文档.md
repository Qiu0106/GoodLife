# 3.1.2 接口

## 1. 模块接口（系统内部模块间接口）

本系统采用 **MVVM 架构**，模块间通过以下方式交互：

| 接口类型 | 说明 | 数据格式 |
|---------|------|---------|
| **Repository → ViewModel** | 数据仓库层通过 `suspend` 函数返回 `Result<T>` 与 ViewModel 交互 | Kotlin Result 包装类 |
| **ViewModel → Activity/Fragment** | 通过 LiveData 观察数据变化 | `LiveData<T>` |
| **数据模型转换** | Bmob 数据模型与前端数据模型双向转换 | `toUser()` / `fromUser()` 等方法 |

### 1.1 Repository 层接口

```kotlin
class BmobRepository {
    // 用户管理
    suspend fun login(phone: String, password: String): Result<User>
    suspend fun register(phone: String, password: String, nickname: String?): Result<User>
    suspend fun updateUser(objectId: String, user: User): Result<User>
    suspend fun getUserByPhone(phone: String): Result<User?>
    
    // 身后事计划管理
    suspend fun createAfterlifePlan(plan: AfterlifePlan): Result<AfterlifePlan>
    suspend fun getAfterlifePlansByUserId(userId: String): Result<List<AfterlifePlan>>
    suspend fun updateAfterlifePlan(objectId: String, plan: AfterlifePlan): Result<AfterlifePlan>
    suspend fun deleteAfterlifePlan(objectId: String): Result<Unit>
    
    // 祭拜信息管理
    suspend fun createVisitInfo(info: AfterlifePlanVisitInfo): Result<AfterlifePlanVisitInfo>
    suspend fun getVisitInfoByPlanId(planId: String): Result<AfterlifePlanVisitInfo?>
    
    // 社区帖子管理
    suspend fun createPost(post: Post): Result<Post>
    suspend fun getAllPosts(): Result<List<Post>>
    suspend fun getPostsByUserId(userId: String): Result<List<Post>>
    suspend fun updatePost(objectId: String, post: Post): Result<Post>
    suspend fun deletePost(objectId: String): Result<Unit>
    suspend fun incrementPostLikes(objectId: String): Result<Unit>
    
    // 评论管理
    suspend fun createComment(comment: Comment): Result<Comment>
    suspend fun getCommentsByPostId(postId: String): Result<List<Comment>>
    
    // 打卡签到管理
    suspend fun getCheckinRecord(userId: String): Result<CheckinRecord?>
    suspend fun createCheckinRecord(record: CheckinRecord): Result<CheckinRecord>
    suspend fun updateCheckinRecord(objectId: String, record: CheckinRecord): Result<CheckinRecord>
    
    // 纪念星管理
    suspend fun createMemorialStar(star: MemorialStarBmob): Result<MemorialStarBmob>
    suspend fun getApprovedMemorialStars(): Result<List<MemorialStarBmob>>
    suspend fun incrementMemorialFlowers(objectId: String): Result<Unit>
    
    // 文件上传
    suspend fun uploadImage(imageFile: File): Result<String>
    suspend fun uploadAvatar(imageFile: File, userId: String): Result<String>
}
```

## 2. 系统间接口（与外部系统交互）

### 2.1 Bmob 后端云接口（REST API）

**基础信息：**
- 接口基础地址：`http://api.bmobcloud.com/1/`
- 文件上传地址：`http://api.bmobcloud.com/2/`
- CDN 地址：`http://bmob-cdn-31634.bmobpay.com/`
- 应用 ID：`b9ab00843ca0d46f85a3d1f8c317164a`

**接口列表：**

| 接口地址 | 方法 | 功能 | 请求头 |
|---------|------|------|--------|
| `/login` | GET | 用户登录 | X-Bmob-Application-Id, X-Bmob-REST-API-Key |
| `/users` | POST | 用户注册 | X-Bmob-Application-Id, X-Bmob-REST-API-Key |
| `/users/{objectId}` | GET | 获取用户信息 | X-Bmob-Application-Id, X-Bmob-REST-API-Key |
| `/users/{objectId}` | PUT | 更新用户信息 | + X-Bmob-Session-Token |
| `/classes/{tableName}` | GET | 查询数据表 | X-Bmob-Application-Id, X-Bmob-REST-API-Key |
| `/classes/{tableName}` | POST | 创建数据 | X-Bmob-Application-Id, X-Bmob-REST-API-Key |
| `/classes/{tableName}/{objectId}` | PUT | 更新数据 | X-Bmob-Application-Id, X-Bmob-REST-API-Key |
| `/classes/{tableName}/{objectId}` | DELETE | 删除数据 | X-Bmob-Application-Id, X-Bmob-REST-API-Key |
| `/files/{fileName}` | POST | 上传文件 | X-Bmob-Application-Id, X-Bmob-REST-API-Key |

**请求示例：**
```http
POST /1/classes/Post HTTP/1.1
Host: api.bmobcloud.com
X-Bmob-Application-Id: b9ab00843ca0d46f85a3d1f8c317164a
X-Bmob-REST-API-Key: fb2a1df255a59958df971f18472cb2b4
Content-Type: application/json

{
    "userId": "user123",
    "title": "测试帖子",
    "content": "这是帖子内容",
    "category": "生活",
    "userName": "张三"
}
```

**响应示例：**
```http
HTTP/1.1 200 OK
Content-Type: application/json

{
    "objectId": "abc123",
    "createdAt": "2024-01-15T10:30:00.000Z",
    "updatedAt": "2024-01-15T10:30:00.000Z"
}
```

**原子计数操作（点赞/献花）：**
```json
{
    "likeCount": {
        "__op": "Increment",
        "amount": 1
    }
}
```

## 1. 核心数据类（内存存储结构）

### 1.1 用户模块数据类

| 类名 | 类型 | 主要字段 | 用途 |
|------|------|---------|------|
| `User` | data class | id, phone, nickname, avatarUrl, gender, birthDate, emergencyContact, bloodType, medicalHistory, signature | 用户实体 |

| `RegisterRequest` | data class | phone, password, nickname | 注册请求参数 |

## 3. 数据同步状态定义

| 状态值 | 常量名 | 含义 | 说明 |
|--------|--------|------|------|
| `0` | `SYNC_STATUS_PENDING` | 未同步 | 本地新增/修改，待上传到云端 |
| `1` | `SYNC_STATUS_SYNCED` | 已同步 | 本地与云端数据一致 |
| `2` | `SYNC_STATUS_FAILED` | 同步失败 | 上传失败，需重试 |

## 5. 关键接口参数说明

### 5.1 Bmob API 通用参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `X-Bmob-Application-Id` | Header | 是 | 应用唯一标识 |
| `X-Bmob-REST-API-Key` | Header | 是 | REST API 密钥 |
| `X-Bmob-Session-Token` | Header | 部分 | 用户登录令牌（修改用户信息时需要） |
| `where` | Query | 否 | 查询条件（JSON格式） |
| `order` | Query | 否 | 排序字段（`-createdAt`表示倒序） |
| `limit` | Query | 否 | 返回条数限制 |
| `skip` | Query | 否 | 跳过条数（分页） |

### 5.2 查询条件格式

```json
// 等于查询
{"userId":"abc123"}

// 多条件查询
{"userId":"abc123","category":"生活"}

// 比较查询（大于）
{"createdAt":{"$gt":{"__type":"Date","iso":"2024-01-01T00:00:00.000Z"}}}
```
